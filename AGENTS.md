# Project Rules (`AGENTS.md`)

## Git Command Policy
- **Never run any `git` commands automatically.** Always ask the user for explicit permission or let the user run `git` commands themselves before executing any `git` CLI command (including `git status`, `git diff`, `git log`, `git add`, `git commit`, `git push`, `git pull`, `git merge`, `git checkout`, `git reset`, `git rebase`, `git stash`, etc.).
